# cityofjoy

> City of Joy Therapy — Luxury doorstep and hotel male massage therapy and wellness sanctuary in Kolkata.

## Features
- **Doorstep & Hotel Service**: Dedicated male-to-male massage therapy delivered across Kolkata.
- **Fast WhatsApp Booking**: Interactive modal with custom service selection, date & time scheduling, and instant WhatsApp concierge routing.
- **Modern Tech Stack**: PHP 8, Tailwind CSS, clean URL routing, Schema.org JSON-LD microdata, and XML sitemaps.
- **Local SEO Optimized**: Targeted metadata, Open Graph cards, Twitter cards, and structured data for high local Google ranking.

## Local Development
Start the local PHP server using the router:
```bash
php -S localhost:8000 router.php
```
Open `http://localhost:8000` in your browser.
